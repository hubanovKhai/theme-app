# Міні-застосунок «Перемикач теми» на Context API

Лабораторна робота з розробки React-застосунку з можливістю перемикання теми.

## Виконані рівні складності
- Рівень 1: Створення ThemeContext, ThemeProvider, використання в 3 компонентах (Header, Content, Footer).
- Рівень 2: Збереження теми в localStorage, кастомний хук useTheme(), атрибут data-theme + CSS-змінні, іконки react-icons.

## Інструкція із запуску
1. Клонувати репозиторій: `git clone https://github.com/hubanovKhai/theme-app.git`
2. Встановити залежності: `npm install`
3. Запустити локальний сервер розробки: `npm run dev`
